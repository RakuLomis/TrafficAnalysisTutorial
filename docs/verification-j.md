## J10 目标规模代表性负载

- 工具：`scripts/loadtest`。
- 场景：100 条学生连接、50 对会话、25 对加密；每端约 5 秒一条；持续 5 分钟。
- 结果：
  - `messages_sent=5900`，`confirmed=5900`
  - `errors=0`，`failures=0`
  - p50 `1.096 ms`，p95 `3.295 ms`，p99 `3.929 ms`，max `5.545 ms`
  - 服务进程内存约 `9.5 MB → 40.9 MB`（峰值 41.8 MB）
- 结论：开发机服务端/协议在代表性负载下满足 p95 ≤ 500 ms；**不代表课堂 Wi-Fi 能承载 100 台手机**，J11/K01 仍需现场验证。
- 附带修复：活动摘要改为 50 ms 窗口、每批 ≤32 条合并，避免 100 端同时发送时逐条广播压满发送队列。

命令：

```powershell
go run ./scripts/loadtest -url ws://192.168.5.5:18086/ws -origin http://192.168.5.5:18086 -clients 100 -duration 5m -interval 5s -encrypted-pairs 25
```
