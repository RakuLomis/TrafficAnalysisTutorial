# 课堂操作卡

## 课前

1. 将 `traffic-classroom.exe` 放在 U 盘或本机任意目录；不需要安装。
2. 电脑接入教室 Wi-Fi 或网线，记下正确的局域网 IPv4。
3. 如自动选择错误，使用 `--iface-ip <IPv4>` 指定；不要选 `0.0.0.0`、`localhost` 或 `169.254.*`。
4. 如需改端口：`--student-addr 0.0.0.0:8080 --teacher-addr 127.0.0.1:8081`，并让管理员只放行学生端口。
5. 双击 EXE，确认控制台显示学生入口和“使用网卡”。
6. 教师页自动打开；二维码应显示真实 LAN 地址。
7. 用一台手机先试：打开页面、加入、看到“加密能力就绪”。

## 课堂流程

1. 学生扫码加入，输入临时昵称。
2. 学生点击在线同学，选择“明文/加密”，发送邀请。
3. 对方接受；明文立即可聊，加密等待“可通信”。
4. 学生点击会话标签进入聊天，发送一条短消息。
5. 教师点击拓扑中的会话边：
   - 明文：观察真实正文。
   - 加密：观察 nonce、密文、payload 字节、WebSocket 字节、方向、间隔。
6. 教师用“暂停观察/恢复观察”冻结投屏，聊天继续。
7. 讲解后点击“新一轮”，学生回到加入页，观察历史清空。
8. 课程结束点击“结束课堂”；确认所有页面状态后，用“退出程序”正常关闭。

## 本机双学生备用演示

没有学生手机时：

1. 打开两个独立浏览器窗口（或普通窗口 + 隐私窗口），都访问学生入口。
2. 分别用昵称 A、B 加入。
3. 按正常流程互发邀请并聊天。
4. 教师页从另一标签页或已自动打开的窗口观察。
5. 两个学生标签页不要刷新；刷新会创建新身份。

## 断线与恢复

- 学生页面短暂断网时会在 60 秒内自动尝试恢复身份。
- 恢复只恢复 ID/昵称/短编号/颜色；旧会话、旧消息和旧密钥不恢复。
- 超过 60 秒或刷新页面，需要重新输入昵称加入。
- 教师页刷新不影响课堂；若 token 丢失，在程序控制台输入 `o` 重新打开。

## 故障速查

| 现象 | 处理 |
| --- | --- |
| 手机打不开 | 确认同一网络；检查 AP 隔离；只放行端口，不关闭整个防火墙 |
| 二维码地址不对 | 控制台看“使用网卡”；重启时加 `--iface-ip` |
| 端口占用 | 显式改两个端口并放行学生端口；不要静默换端口 |
| 教师页关闭 | 控制台输入 `o`；不要关闭 EXE 控制台窗口 |
| 学生满员/限速 | 开始新一轮清理；检查在线人数和连接上限 |
| 加密协商失败 | 刷新双方页面重新邀请；确认浏览器不是极旧版本 |

## 退出

- 优先用教师页“退出程序”。
- 也可在控制台输入 `q` 或按 Ctrl+C。
- 直接关闭控制台窗口可能强制终止进程；学生页面会随后显示断线。
- 退出后重新启动是全新一轮，不保留参与者、会话或观察记录。
