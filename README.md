# 局域网加密流量课堂工具

一个从 U 盘运行的课堂演示工具：教师电脑作为局域网转发点 A，学生用手机浏览器加入，通过逻辑会话进行明文或端到端加密聊天。教师在本机页面点击会话边，观察 A 实际收到的应用消息与通信特征。

## 适用场景

- 课堂讲解“加密流量分析能看到什么、不能看到什么”。
- 对比明文与 `nacl.box` 端到端加密在转发点的可见差异。
- 观察消息长度、方向、时间间隔、次数和方向切换。

## 系统要求

- 目标系统：Windows 10/11 x64。
- 教师电脑：运行 EXE，已有浏览器。
- 学生设备：与教师电脑同一局域网，手机浏览器。
- 不需要：Go、Node.js、Python、数据库、抓包驱动、二维码在线服务、外网。

> 当前实际验证环境为 Windows 10 Pro 19045 x64 与开发机 WLAN；Android/iPhone 真机与最终教室网络仍按计划验收。

## 快速开始

1. 双击 `traffic-classroom.exe`。
2. 程序启动学生入口 `http://<局域网IPv4>:8080/`，并自动打开本机教师页 `http://127.0.0.1:8081/#token=...`。
3. 教师页显示二维码。学生手机连接同一 Wi-Fi 后扫码或输入地址。
4. 学生输入临时昵称加入；点击在线同学选择对象，选择“明文”或“加密”，发送邀请。
5. 对方接受后出现会话边。点击自己的会话边或会话标签进入聊天。
6. 教师点击拓扑中的任意会话边，查看 A 实际收到的内容与统计。
7. 教师可暂停/恢复观察、开始新一轮、结束课堂或正常退出程序。

控制台命令（仅在有交互控制台时可用）：

- `o`：重新打开带 token 的教师页
- `q`：正常退出
- `h`：帮助

## 加密与隐私边界

- 加密在发送端浏览器完成，接收端浏览器解密；A 只转发公钥、密文和允许的元数据。
- 加密会话在教师观察页显示真实 nonce 与密文，不显示明文；明文会话按设计显示真实正文。
- 聊天、身份凭据和密钥只存在内存中；进程重启无旧数据。
- 教师入口只绑定 `127.0.0.1`，管理 token 只通过本机页面 fragment 传入，不进入学生服务或默认日志。
- 观察动画表示“A 接受了一条业务消息”，不是网卡抓包、链路路径或实测传播速度。
- `payload_bytes` 与 `ws_message_bytes` 都不是 IP/TCP 包长。

## 构建

开发机需要：

- Go 1.22.6（构建脚本设置 `GOTOOLCHAIN=local`）
- Node.js 24.x / npm 11.x
- PowerShell 7+

```powershell
pwsh -NoProfile -File scripts/build.ps1 -Version 0.1.0-dev
```

产物：`bin/traffic-classroom.exe`。脚本先 `npm ci`、构建前端、复制到 `internal/web/dist`，再编译内嵌资源的 Windows EXE。依赖版本记录在 `go.mod`、`go.sum`、`web/package-lock.json`。

生成发布目录：

```powershell
pwsh -NoProfile -File scripts/package.ps1 -Version 0.1.0-dev
```

输出到 `dist/traffic-classroom-<version>/`，包含 EXE、使用说明、课堂操作卡、第三方许可、版本信息和 SHA-256。

## 常用参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--student-addr` | `0.0.0.0:8080` | 学生监听地址 |
| `--teacher-addr` | `127.0.0.1:8081` | 教师监听地址，必须 loopback |
| `--iface-ip` | 自动选择 | 二维码/展示使用的 LAN IPv4 |
| `--no-open` | 关闭 | 不自动打开教师页 |
| `--version` | - | 打印版本、提交与构建时间 |

端口冲突时程序不会静默换端口，请显式修改参数并同步放行防火墙。

## 故障排查

| 现象 | 检查 |
| --- | --- |
| 手机打不开页面 | 是否同一 Wi-Fi；是否 AP/客户端隔离；Windows 防火墙是否放行学生端口 |
| 二维码地址错误 | 用 `--iface-ip` 指定正确网卡；不要在二维码中出现 `0.0.0.0`/`localhost` |
| 教师页丢失 | 控制台输入 `o` 重新打开；不要关闭承载 EXE 的控制台窗口 |
| 学生被满员拒绝 | 检查在线人数上限与原始连接上限；重启或开始新一轮清理 |
| 断线后无法恢复 | 同页恢复窗口 60 秒；刷新页面会创建新身份 |
| 加密选项不可用 | 浏览器缺少安全随机数或密码库；明文仍可使用 |

## 已知限制

- 文件传输、音视频、群聊、WebRTC、真实抓包、TLS 复现、账号密码、数据库、历史导出与公网部署不在 V1。
- 未实测的 Windows 版本、手机型号、浏览器版本不宣称支持。
- 100 个模拟连接只能说明服务端/协议表现，不等于课堂 Wi-Fi 能承载 100 台手机。
- 固定长度填充等扩展不纳入 V1。
